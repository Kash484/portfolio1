<h3>About the Gate Game 🚪</h3>
<blockquote>The Gate Game is a multi-stage JavaScript game built on top of an object-oriented engine. The project is split into three connected sublevels — <strong>Cannon Ball</strong>, <strong>Escape Room</strong>, and <strong>Zone Catch</strong> — each one exercising a different set of CS 111 concepts under a shared engine.</blockquote>

<p><strong>Object-Oriented Programming:</strong> Every sublevel is wrapped in its own class (<code>GameLevelCannonball</code>, <code>GameLevelEscaperoom</code>, <code>GameLevelZonecatch</code>) that accepts a <code>gameEnv</code> in its constructor and assembles the level out of engine primitives. Entities like <code>Player</code>, <code>Npc</code>, <code>Enemy</code>, and <code>Collectible</code> all inherit from a shared <code>GameObject → Character</code> base chain, so each level just composes the pieces it needs.</p>

<pre><code>// Composition through the engine's class hierarchy
{ class: Player,      data: sprite_data_player    },
{ class: Npc,         data: sprite_data_gatekeeper },
{ class: Enemy,       data: sprite_data_cannon    },
{ class: Collectible, data: sprite_data_key       },
</code></pre>

<p><strong>Methods &amp; Parameters:</strong> Engine classes expose overridable methods like <code>update()</code>, <code>draw()</code>, and <code>handleCollision(other, direction)</code>. Each sublevel customizes behavior through helper functions — for example, a zone-builder that converts a relative rectangle into pixel-space configuration.</p>

<pre><code>// Helper that takes parameters and returns a config object
function zone(id, [rx, ry, rw, rh]) {
  return {
    id,
    x: Math.round(rx * width),
    y: Math.round(ry * height),
    w: Math.round(rw * width),
    h: Math.round(rh * height),
  };
}
</code></pre>

<p><strong>Control Structures &amp; Data Types:</strong> Arrays hold level data (cannon trajectories, room puzzles, capture zones), booleans gate state (<code>isLocked</code>, <code>hasKey</code>, <code>zoneCleared</code>), and strings handle sprite paths and dialogue lines fed into the <code>DialogueSystem</code>.</p>

<pre><code>// Arrays of object literals drive the level layout
const cannons = [
  { id: 'c1', x: 0.10, y: 0.80, angle: 45, power: 12 },
  { id: 'c2', x: 0.50, y: 0.70, angle: 30, power: 15 },
  { id: 'c3', x: 0.85, y: 0.85, angle: 60, power: 10 },
];
</code></pre>

<p><strong>Input/Output &amp; Async:</strong> Player movement runs through the engine's keyboard listeners; the gatekeeper NPC triggers async transitions when a sublevel is cleared, using <code>requestAnimationFrame</code> for the fade and <code>setTimeout</code> to hand control to <code>GameControl.transitionToLevel()</code>.</p>

<pre><code>// Async hand-off to the next gate
requestAnimationFrame(() => {
  fade.style.opacity = '1';
  setTimeout(() => {
    topGame.transitionToLevel();
  }, 800);
});
</code></pre>
